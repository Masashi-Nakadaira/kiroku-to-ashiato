# UI v6

シナリオ、3Dモデル、調査による進行、セーブ形式はv5と同じです。

- PCでは現場に調査・会話の帯を重ねます
- スマートフォンの縦画面では下部シート、低い横画面では横並びになります
- 「現場」「手帳」「推理」で画面を切り替えます
- 手帳には発見した記録と自分のメモをまとめています
- 会話履歴は記録された会話を聞いた順に読み返せます。同じ会話はまとめて表示します
- 比較・記録提示・説明の仕組みは従来通りです。記録が増えるのは実際の調査後だけです
- 「現場を広く見る」でシートを折りたためます。ドラッグは不要です
- Tabで操作へ移動し、Enter/Spaceで選べます。Escapeでダイアログを閉じ、推理・手帳から現場へ戻れます
- 画面切り替えでは選択やメモを残します。模型の視点操作は調査記録を自動追加しません
- 3Dを表示できないときは同じ地点・行動を見取り図と場所選択から利用できます

## 検証

公開用の `npm test` はネタバレを含めないUIスモークテストです。開発時には既存シナリオ・全101行動・移行処理等も含む111件の回帰テストを実施しています。

クラウドブラウザーではWebGLが無効のため、実画面確認は2Dフォールバックで行っています。実際の3D表示の最終目視確認はこの環境では実施できていません。
