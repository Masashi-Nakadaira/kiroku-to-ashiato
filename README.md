# 記録と足跡 — 3D調査版

二つの独立した事件を、証拠と回して調べられる3D模型から解く推理ゲームです。

- **井戸端の合図**：時計のない村。鐘と二つの呼び声から、種蔵の印が消えた間を調べます
- **応答する空席**：代理AIが話す近未来。本物の記録が何を観測したのかを分け、原本ディスクの交換を調べます

## 遊び方

GitHub Pages の公開設定後、次のURLから遊べます。

https://Masashi-Nakadaira.github.io/kiroku-to-ashiato/

ダウンロードした場合はフォルダー全体を展開し、index.html をブラウザーで開いてください。サーバー、アカウント、APIキーは不要です。

模型はドラッグで回転、ホイールや2本指操作で拡大できます。番号ボタンか証拠目録から証拠を読み、出来事を組み立て、結論と根拠を提出します。困ったらヒントを順に開いてください。5枚目には結論が含まれます。

キーボードではTabで移動、Enter/Spaceで選択します。模型にフォーカスすると矢印キーで回転、＋/−で拡大縮小、0/Homeで視点を戻せます。WebGL2を使えない場合も「見取り図」と全証拠で最後まで遊べます。

模型は発見後の説明図です。人の不在やトレイの開閉状態を、事件当時の所在・時刻として読み替えないでください。

## 保存

進行はブラウザー内に保存します。「進行をファイルに保存」と「保存ファイルを読込」も使えます。ブラウザーのデータ削除やプライベートブラウズでは自動保存が失われる場合があります。

音は初期状態でオフです。必要な情報は文章で読めます。ゲーム本体に解析・追跡コードや外部APIへの通信はありません。

## 3D表示の再ビルド

遊ぶだけならインストールは不要です。Node.jsを使用して3D表示を再ビルドする場合のみ実行します。

    npm ci --ignore-scripts
    npm run build

ビルド済みの scene3d.js と、src/・scripts/ のソースを含みます。Three.js のライセンスは vendor/THREE-LICENSE.txt と scene3d.js.LEGAL.txt を参照してください。
