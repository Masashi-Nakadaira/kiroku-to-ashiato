# 記録と足跡

中世の村と、近未来の資料館を調べる、短い推理ゲームです。

- [ゲームを開く](https://masashi-nakadaira.github.io/kiroku-to-ashiato/)
- 丸い印から場所を選び、物や人に対して行動します
- 発見した記録は手帳で読み返し、並べたり相手に示したりできます
- ヒントは自分で開いたときだけ表示されます
- 3Dを表示できない環境では、見取り図で同じ調査を行えます

## 保存

進行はブラウザー内に保存します。「進行を保存」でファイルへ書き出すこともできます。
v4の村の進行はv5へ引き継ぎます。近未来は新しい事件として始まり、旧版の進行は別保存のまま残ります。旧近未来は `future-v2.html` で開けます。v1〜v3の村はメモを残し、新しい調査を初めから始めます。

## ローカルで開く

`index.html` をブラウザーで開けます。外部通信・アカウント・有料サービスは必要ありません。3DにはWebGLを利用します。端末によって表示できない場合も、見取り図で調査を進められます。

## ビルド

Node.js環境で `npm ci`、`npm run build` を実行します。固定バージョンのThree.jsとfflateを使用します。モデルはgzipから復元され、オフライン用ラッパーも再生成されます。

人物は調査時点の静止した人形です。模型の視点操作で調査記録が自動的に増えることはありません。
