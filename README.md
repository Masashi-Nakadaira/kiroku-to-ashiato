# 記録と足跡 v3 — 証言更新版

中世の新章と、従来の近未来の事件を遊べる、無料・オフライン対応の推理ゲームです。

## 始め方

フォルダー全体を展開して `index.html` をブラウザーで開きます。インストール、アカウント、APIキー、ネット接続は不要です。JavaScript、CSS、assets は一緒に置いてください。

## 中世の新章

祭りのため故郷へ帰った、町の書記の若い助手。教会から銀の聖杯がなくなり、幼なじみも疑われています。

- 小さな教会と鐘楼、四人の服を着た人物がいる立体模型
- 同じ模型を使う字幕つきの序幕。カメラが場面を移動します。音声はありません
- 場所を選んで、対象を調べたり話を聞いたりする調査
- 食い違いの説明を組み立てると、証言が変わり、新しい質問や場所が現れる仕組み
- 読んだ枚数だけでは証言は変わりません
- 以前の証言も、改めた証言も調査記録に残ります
- 最後は証拠番号ではなく、説明文の続きを選んで推理をつなぎます

近未来の事件は「従来版の事件を開く」から、独立した `future-v2.html` へ進みます。物語・証拠・正解に加え、順序・記録分類・痕跡・証拠引用の操作も旧版のままです。事件一覧へのリンクでv3へ戻れます。近未来には中世のような段階的な証言更新はありません。

## 操作

1. 模型の番号か場所一覧から、行き先を選びます
2. そこで調べる対象・質問を選びます。発見した資料だけが調査記録に残ります
3. 「証言を問い直す」で、食い違いを説明します
4. 話がつながったら「推理をつなぐ」で結論を提出します

誤答しても発見やメモは失われません。項目ごとの正誤表示はありません。ヒントは任意で、最後には結論を含みます。

模型はドラッグや矢印キーで回転、ホイール・＋/−で拡大できます。視点ボタンと屋根の取り外しも観察用です。人形の位置は調査時点のもので、事件時のアリバイではありません。

WebGLを使えない環境では、見取り図で同じ調査と推理を最後まで行えます。細かい現場の事実は文章と詳細図にも記録されるため、小さな物を画面上で探し当てる必要はありません。

## 序幕

序幕はスキップでき、調査画面から再生できます。「前の場面」「次の場面」「一時停止」で操作できます。動きを減らす設定ではカメラは瞬時に切り替わり、字幕は手動で進みます。序幕を飛ばしても必要な事情は事件の前提や聞き取りに残ります。

## 保存

進行はブラウザー内に自動保存します。「進行をファイルに保存」でJSONの控えを作れます。「保存ファイルを読込」は置き換える前に確認します。近未来の保存を含むファイルでは近未来も置き換えます。

旧版の中世はメモと設定を引き継ぎ、調査・推理・解決記録を初めからにします。v2の近未来の進行は上書き前に専用の保存先へコピーし、従来版で続けられます。v3のファイル保存には、このブラウザーにある近未来の保存も同梱します。変更はタイトル画面にも表示します。

この事件を最初から、は確認後に当該事件だけを消します。もう一つの事件は残ります。

## 検証・開発

```
npm ci --ignore-scripts
npm run build
```

この公開リポジトリには、ゲーム本体・表示用ソース・模型生成用ソース・ビルド設定・ライセンスを含めています。開発用の検証資料とテストは含めていません。

- `scripts/model-v3/`：Blender用の模型生成・書き出しソース
- `src/`：Three.js表示・カメラのソース
- `assets/models/*.glb.js`：オフライン読み込み用の模型ラッパー
- `future-v2.html` と `legacy/`：従来の近未来事件

実ブラウザーのWebGL描画・実タッチ・FPSは未検証です。Blenderのプレビューや自動テストは、実ブラウザーの3D動作保証ではありません。

外部フォント、課金サービス、AI API、解析・追跡コードは使っていません。Three.jsのライセンスはvendor内にあります。

## 模型の配布形式

中世の模型は `assets/models/village.glb.gz` と圧縮済みのオフラインラッパーで配布します。読み込み時に元のGLBへ可逆復元し、長さ・CRC・GLBヘッダーを確認します。模型の形や内容は圧縮前と同一です。外部通信やブラウザー固有の解凍APIは不要です。

開発用の `npm run build` は、圧縮ファイルからローカルの `village.glb` を復元します。この生成ファイルはGit管理・公開用一覧から除外します。近未来の模型の配布形式は変更していません。fflate 0.8.2は固定版Three.jsに同梱されているものを使用し、MITライセンスをvendorに同梱しています。
