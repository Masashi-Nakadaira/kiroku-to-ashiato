# 記録と足跡 — 自由調査版 v4

里帰りした村で、銀の聖杯の紛失と、水車の停止を調べる推理ゲームです。五人の話と現物を、自分で確かめていきます。

`index.html` を開いて遊べます。フォルダー全体をダウンロードすれば、ネット接続なしでも開けます。アカウントやAPIキーは不要です。

- 場所、物や人、具体的な行動の順に選びます
- 見つけた二つの記録を比べたり、相手に示して質問できます
- どちらの出来事からでも調べられ、解決後も調査を続けられます
- 3D模型が使えないときは見取り図で最後まで遊べます
- ヒントは任意です。最後のヒントには結論が含まれます

模型の視点操作だけでは手がかりは取得されません。人物は調査時点の位置で、事件当時の居場所を示すものではありません。

## 保存

ブラウザー内への自動保存と、進行ファイルの保存・読込に対応しています。v1〜v3の中世の進行は、メモと設定を残して初めからになります。近未来の従来版は独立した保存先で、従来の物語と操作のまま遊べます。

## 表示バンドルの再構築

Node.jsがある環境では `npm ci --ignore-scripts` と `npm run build` で表示バンドルを再構築できます。

中世模型はgzipとオフラインラッパーで収録し、同梱fflateで元のGLBへ復元します。近未来模型は従来の形式です。Three.jsとfflateのライセンスは `vendor` にあります。外部フォント、AI API、追跡・解析コードは使っていません。
